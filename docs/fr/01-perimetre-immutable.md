# 1. Périmètre des contrats Immutable

Ce dépôt fournit une bibliothèque de contrats Solidity destinée aux développeurs qui construisent sur Immutable X et Immutable zkEVM. Il regroupe des briques curatées pour les tokens, le bridging, les marketplaces, les AMM et les smart contract wallets.

Le parcours porte sur l’architecture publiée et sur les interfaces utiles à une DApp. Il ne remplace pas une revue de sécurité ni la documentation opérationnelle du réseau.

L’écosystème visé est une L2 permissionless à preuve de connaissance nulle, avec des contrats réutilisables plutôt qu’une application complète. Cette séparation permet de choisir une surface fonctionnelle adaptée à chaque projet.
