# 6. Sécurité et limites

Le dépôt indique que les contrats sont expérimentaux, susceptibles d’évoluer et qu’ils doivent encore être audités ou revus avant un usage en production. Cette réserve est centrale pour toute DApp qui manipule des actifs.

La surface de risque comprend les permissions de mint, les rôles d’opérateurs, les bridges, les dépendances Seaport et les hypothèses propres à la L2. Les remappings et peer dependencies doivent être figés et relus avec le code effectivement consommé.

La licence affichée est Apache-2.0. La présente série est un parcours documentaire basé sur la lecture statique du dépôt : aucune installation, compilation, exécution ou déploiement n’a été réalisé ici. Pour une vérification active, consulter la suite de tests et les consignes de build du dépôt.
